# Маленькие use-case файлы для проверки правил ФОТ

Все кейсы рассчитаны на январь 2026 и лежат парами:

- `*_input.xlsx` — входной файл;
- `*_result.xlsx` — результат расчёта;
- `use_cases_summary.xlsx` — сводка по выплатам.

## Кейсы

| Кейс | Что проверяет | Ожидаемое наблюдение |
|---|---|---|
| `uc01_122_same_contract` | 122 только на договоре с окладом | `C_MAIN`: оклад 40 400 + 122 59 600 |
| `uc02_goz_min_2556_bep` | ГОЗ: минимум из 2556 и БЭП | `C_GOZ`: оклад 40 400 + 122 39 599,99 + приказ 20 000,01 |
| `uc03_124_only_allowed_contract` | 124 только на договоре, где она разрешена | `C_124`: 124 = 40 000; на `C_NO_124` выплат нет |
| `uc04_priority_staff_when_salary_on_priority` | Приоритет, если штатная схема возможна | `C_PRI`: оклад 40 400 + 122 59 600, без 152 |
| `uc05_priority_152_when_salary_elsewhere` | Приоритет, если оклад на другом договоре | `C_BASE`: оклад 40 400; `C_PRI`: 152 = 59 600 |
| `uc06_labor_salary_122` | Трудоёмкость закрывается окладом+122 | Контроль трудоёмкости: план 100 000, факт 100 000 |
| `uc07_labor_salary_152` | Трудоёмкость закрывается окладом+152 | Контроль трудоёмкости: план 100 000, факт 100 000 |
| `uc08_labor_order_not_counted` | Приказ не закрывает трудоёмкость | Деньги выплачены, но контроль трудоёмкости показывает недозакрытие |
