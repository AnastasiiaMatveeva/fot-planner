# ADR: атрибуция трудоёмкости по строке РКМ

- Статус: принято и реализовано
- Дата: 2026-09-11
- Связанные правила: 16–20 в `docs/ПРАВИЛА_РЕШАТЕЛЯ.md`

## Контекст

Один сотрудник может подходить нескольким строкам РКМ по должности или правилу
замещения. Если дробить его месячную ставку между подходящими строками, решатель
может искусственно подогнать среднюю стоимость. В отчёте при этом появляются
доли вроде 0,48 и 0,52, хотя ставка человека на конкретном договоре оформлена
на одной должности.

## Решение

Для сочетания «сотрудник — договор — месяц» трудоёмкость и относимые выплаты
закрывают не более одной строки РКМ. Человеко-месяцы создаёт открытая ставка на
этом договоре; надбавки сами по себе объём не создают. Деньги относятся на ту
же строку, кроме выплат, которые предметное правило исключает из трудоёмкости.

Совместимость направленная: сотрудник закрывает свою строку или строку, для
которой его должность разрешена справочником замещения. Его собственная
должность и оклад от этого не меняются.

Двоичный признак `labor_on` создаётся только когда человеку подходят несколько
строк. При единственной строке используется уже существующий признак оклада,
чтобы не раздувать MIP лишними переменными.

## Последствия

- отчёт соответствует кадровому смыслу одной ставки на договоре;
- число людей по строке считается по фактически отнесённым людям;
- решатель не может улучшить среднюю стоимость дроблением одного человека;
- ограничение относится к одному договору: работа человека на другом договоре
  рассматривается отдельно.

## Проверка

Основное покрытие находится в кризис-сценариях трудоёмкости и замещения. В
матрице требований нужно отдельно удерживать отрицательный случай, где один
человек подходит двум строкам и попытка дробления запрещена.
