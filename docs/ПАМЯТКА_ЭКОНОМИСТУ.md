# Данные сервиса: что входит и что выходит

Описание для экономиста: какие данные сервис читает, какие показывает и что
лежит в каждой графе. Простыми словами, без служебных имён.

Две части: **вход** — данные организации и решения плана, из которых собирается
расчёт; **выход** — отчёт «План ФОТ» и служебные листы результата. В конце —
общие перечни (виды выплат, состояния, единицы) и короткая карта «документ →
таблица».

Это описание, а не правило: правила расчёта живут в `docs/ПРАВИЛА_РЕШАТЕЛЯ.md`,
происхождение чисел — в `docs/ИСТОЧНИКИ.md`. Где описание и карточка требования
разойдутся, права карточка.

# Часть 1. Входные данные

## 1.1. Что экономист приносит и что из этого берётся

| Документ | Что из него берётся | Куда попадает |
| --- | --- | --- |
| Штатное расписание | люди, должности, ставки, занятость, категории, сроки работы, разрешённые и запрещённые договоры | таблица «Штатное расписание» |
| Документ зарплаты по месяцам | сумма к выплате за каждый месяц года | таблица «Заработная плата по месяцам» |
| Карточка и документы договора | шифр, наименование, сроки, фонд, лицевой счёт, ГОЗ, разрешённые виды выплат, этапы и трудоёмкость | таблица «Договоры» и трудоёмкость договора |
| Перечень должностей | список должностей и категории персонала | «Справочник должностей» |
| Приказ № 2556, справки П4 и БЭП, положение об окладах | оклад за полную ставку, пределы, средний лимит по ГОЗ | «Справочник должностей» |
| Таблица замещения должностей | какую должность можно закрыть другой | «Правила замещения» |
| Документ по надбавке 120 | кому и на какой срок положена надбавка за гостайну, какой процент | «Надбавка 120» |
| Приказ о рабочей группе | состав группы, срок, вид работ, руководитель | рабочая группа договора |
| Выгрузка 1С «Штатное расписание на дату» | факт начислений за прошедшие месяцы: кто, с какого договора, каким видом, сколько, по какой ставке | «Факт начислений» |
| Справочник подразделений (или ввод экономиста) | к какому управленческому подразделению относится человек | «Управленческие подразделения» |

Пока найденные в документе строки не подтверждены, в расчёт они не идут.

## 1.2. Штатное расписание

Строка таблицы — одна запись человека: должность и ставка. У человека может быть
несколько строк (например, инженер на полную ставку и аналитик на четверть по
совместительству).

| Графа | Что в ней |
| --- | --- |
| Табельный номер | ключ человека: строки с одним номером принадлежат одному человеку |
| ФИО | как называть человека в отчётах |
| Должность | по ней берутся оклад и пределы из справочника |
| Подразделение | где человек работает; по нему же ограничивается вторая ставка той же должности |
| Лицевой счёт | справочно: где человек числится сейчас |
| Рабочие группы | договоры, членами рабочей группы которых он является по приказу |
| Ставка | доля должности в этой строке: 0,25 · 0,5 · 0,75 · 1,0 |
| Занятость | основное место или совместительство; пусто — сервис определит сам |
| Категория | основной работник, студент, аспирант — от неё зависят пределы ставок |
| Начало, Окончание | с какого и по какое число строка действует |
| Разрешённые договоры | на какие договоры человека можно назначать (пусто — на любые) |
| Запрещённые договоры | на какие нельзя |

Зарплаты в этой таблице нет: сумма к выплате живёт в отдельной таблице по месяцам.

## 1.3. Заработная плата по месяцам

Строка — человек; графы — месяцы года плана. Сумма может меняться в течение года:
например, с апреля новая. Если у человека две строки зарплаты (например, в двух
подразделениях), в расчёте его зарплата месяца — сумма этих строк.

| Графа | Что в ней |
| --- | --- |
| Табельный номер | чей это месяц |
| ФИО | для чтения таблицы |
| Управленческое подразделение | для отчёта руководству; на расчёт не влияет |
| Январь … Декабрь | сколько человеку положено за этот месяц; месяц вне срока работы суммы не требует |
| Итого | сложение по строке, считается сервисом |

Месяц срока без суммы — не «ноль», а пробел в данных: расчёт с ним не начнётся,
пока сумма не заполнена. Ноль пока не принимается.

## 1.4. Договоры

Строка — договор.

| Графа | Что в ней |
| --- | --- |
| Шифр | как договор опознаётся во всех остальных таблицах; не меняется |
| Наименование | тема работы; можно переименовать |
| Номер договора | справочно |
| Признак | ГОЗ, «Приоритет 2030» или пусто |
| Структурное подразделение | подразделение договора: вторая ставка той же должности возможна только на договоре другого подразделения |
| Лицевой счёт | куда относятся выплаты; счёт, начинающийся на 23, — особый случай для надбавки 120 без оклада |
| Гособоронзаказ | да — включается контроль среднего лимита по договору |
| ФОТ, ₽ | сколько всего можно выплатить по договору за год |
| Начало, Окончание | окно, в котором договор платит |
| Выплата оклада до, Выплата надбавок до | крайние сроки выплат; пустое поле означает дату окончания договора |
| Разрешённые виды начислений | оклад, 120, 122, 124, 152, стимулирующая приказом — единственный выключатель выплат |
| Основное место работы | можно ли открывать на договоре основную ставку |
| Внутреннее совместительство | можно ли открывать совместительство |
| Приоритет 2030 | на договоре программы в месяце либо штатные выплаты, либо надбавка 152 |
| Документов | сколько файлов загружено в договор |

## 1.5. Справочник должностей

Строка — должность. Величины хранятся с датой «действует с»: оклад может
индексироваться с сентября, приказ вступать с декабря. В месяце действует
величина на первое число.

| Графа | Что в ней |
| --- | --- |
| Должность | название; сравнение названий буквальное |
| Категория персонала | НТП, НР, АУП, ППС, ПП — от неё зависит, применяется ли уровень П4 |
| Оклад за 1,0 ставки, ₽ | оклад на полную ставку; на его основе считается оклад по открытой ставке |
| П2556, ₽ | потолок «оклад плюс 122» на полную ставку и отдельно потолок для выплаты приказом |
| П4, ₽ | уровень штатной части в месяцы с надбавкой 124 (для НТП и НР) |
| БЭП, ₽ | средний лимит «оклад плюс 122» на полную ставку по договорам ГОЗ |
| Примечание | свободный текст, например почему величины нет |
| Действует с | с какой даты величина действует; прежняя величина остаётся до новой даты |

## 1.6. Правила замещения

| Графа | Что в ней |
| --- | --- |
| Должность работника | чья это строка штатного расписания |
| Допустимые должности для дополнительной ставки | какие должности можно закрыть этим человеком; направление одностороннее |
| Источник | откуда правило взято: файл организации или решение экономиста |

## 1.7. Надбавка 120

Строка — пара «сотрудник и договор секретности». У одного человека может быть
несколько строк с разными сроками.

| Графа | Что в ней |
| --- | --- |
| Сотрудник | кому положена надбавка за гостайну |
| Ставка, % | процент от оклада; пустое значение читается как 5 % |
| Договор секретности | договор, который задаёт срок допуска |
| Начало, Окончание | срок выплаты надбавки; пусто — срок договора секретности |
| Договор выплаты | с какого договора платить; пусто — сервис выберет сам |
| Источник | откуда строка взята |

## 1.8. Трудоёмкость договора

Строка — плановая работа договора: должность, объём в человеко-месяцах и
стоимость. Приходит из РКМ, структуры цены или плана работ.

| Графа | Что в ней |
| --- | --- |
| Этап | этап или раздел работ |
| Вид работ | описание работы |
| Должность | кем эта строка закрывается |
| Кол-во человек | сколько специалистов планируется |
| На 1 человека | сколько человеко-месяцев приходится на одного |
| Чел.-мес. | общий объём строки в человеко-месяцах |
| Средняя, ₽ | плановая средняя стоимость одного человеко-месяца |
| Начало этапа, Окончание этапа | в какие месяцы работа выполняется |
| Январь … Декабрь | план по месяцам, если он задан в документе |
| Год | год плана |
| Всего по источнику | сколько человеко-месяцев было в документе целиком |
| Источник | из какого документа и места строка взята |

## 1.9. Факт начислений

Строка — одно начисление за прошедший месяц. Приходит из выгрузки 1С или из
плоской таблицы.

| Графа | Что в ней |
| --- | --- |
| Табельный номер | кому начислено |
| Договор | с какого договора |
| Месяц | за какой месяц |
| Вид выплаты | оклад, 120, 122, 124, 152, приказ |
| Сумма, ₽ | сколько начислено |
| Ставка | открытая ставка на договоре в этом месяце; обязательна для оклада, для остальных пуста |
| Основное место | было ли это основное место; пусто — сервис определит по наибольшей ставке |

## 1.10. Рабочая группа договора

| Графа | Что в ней |
| --- | --- |
| Табельный номер | член группы; если строку не удалось сопоставить с человеком, сервис попросит выбрать |
| ФИО | как в приказе |
| Должность | должность по приказу |
| Вид работ | что человек делает по приказу |
| Приказ | документ-основание |
| Срок группы | по какое число действует состав |
| Действие | текущий состав по последнему приказу или снятие |
| Руководитель, Подразделение | справочно |

Член рабочей группы — это закрепление без вида выплаты: с договора группы в
каждом месяце срока должна быть хотя бы одна выплата. Снять такое закрепление
можно только приказом.

## 1.11. Управленческие подразделения

| Графа | Что в ней |
| --- | --- |
| Наименование | название подразделения для отчёта руководству |
| Порядок | в каком порядке показывать |
| Строк зарплаты | сколько строк зарплаты к нему отнесено |

На расчёт подразделения не влияют: они делят выплаты в отчёте.

## 1.12. Что относится к плану, а не к реестру

План — это решение «что берём в этот расчёт». Реестр от правок плана не меняется,
а нетронутое в плане следует за реестром.

| Что задаётся в плане | Что означает |
| --- | --- |
| Отметка договора | участвует ли договор в этом расчёте вместе со своей трудоёмкостью и надбавкой 120 |
| Версия документа | какая редакция документа идёт в расчёт: последняя или прежняя |
| Разрешённые виды выплат | переопределение отметок договора для этого плана |
| Начало, Окончание | переопределение срока договора |
| Основное место, Совместительство | переопределение разрешений договора |
| Оклад до, Надбавки до | переопределение крайних сроков выплат |
| Месяцы без выплат | в отмеченные месяцы с договора не платят никому |
| Правка ставки, начала и окончания строки | «а что если» для человека; в соседних планах не видна |
| Правка суммы месяца | своя сумма зарплаты для этого плана |
| Снятие строки с расчёта | строка уходит из этого плана вместе с надбавкой 120, суммами и закреплениями |
| Закрепление | с какого договора платить человеку: с видом выплаты, без вида, «только» или «по возможности вся» |
| Запрет | с какого договора платить нельзя и в какие месяцы |
| Настройки расчёта | см. ниже |

Все решения плана называются в допущениях расчёта — их видно перед запуском.

## 1.13. Настройки расчёта

| Настройка | Что означает |
| --- | --- |
| Год | год плана |
| Недоплата заработной платы разрешена | можно ли принять план с недоплатой; без разрешения недоплата невозможна |
| Наибольшее число договоров оклада в год | сколько разных договоров могут быть источником оклада у человека за год (считается по человеку, а не по строке) |
| Допуск трудоёмкости, % | насколько разрешено отклониться от плановой трудоёмкости; не больше 5 % |
| Факт по месяц | последний прошедший месяц: месяцы до него берутся как есть и не пересчитываются |
| Веса предпочтений | чем важнее та или иная цель (ровное освоение, стабильность сумм, меньше приказов); меняются словами в чате |
