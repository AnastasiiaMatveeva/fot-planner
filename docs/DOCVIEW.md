# Просмотр документов в карточке

Карточка документа показывает файл двумя видами: «Документ» — как он
выглядит, «Текст» или «Таблица» — разметка, по которой работают выделение
для замечаний и подсветка «Извлечено».

## Как получается вид «Документ»

Браузер не умеет открывать `.xlsx` и `.doc`, поэтому файл приводится к PDF:

1. Установленный Office печатает документ (`_office_to_pdf` в `app/main.py`).
   Перед печатью раздвигаются столбцы, где текст обрезан соседней ячейкой, и
   подбирается высота строк — иначе Excel печатает обрезанный текст.
2. Если Office нет — то же делает LibreOffice (`_soffice_to_pdf`).
3. Готовый PDF кэшируется в `app/data/previews`; печать запускается заранее,
   сразу после разбора документа, чтобы карточка открывалась без ожидания.

Печать книги занимает у Excel около десяти секунд — это плата за то, что
вид совпадает с файлом.

## ONLYOFFICE вместо печати (опыт)

Если задана настройка `FOT_ONLYOFFICE_URL`, вкладка «Документ» показывает
файл просмотрщиком ONLYOFFICE: он открывает `.xlsx`, `.docx` и `.pdf`
постранично сам, без Office на машине и без ожидания печати.

```
FOT_ONLYOFFICE_URL=http://localhost:8360/web-apps/apps/api/documents/api.js
FOT_SELF_URL=http://host.docker.internal:8770
```

`FOT_SELF_URL` — адрес нашего сервиса, по которому **сервер ONLYOFFICE**
заберёт файл: документ скачивает он, а не браузер, и изнутри контейнера
«localhost» — это сам контейнер.

Свой сервер поднимается в докере:

```
docker run -d --name fot-onlyoffice -p 8360:80 -e JWT_ENABLED=false \
  onlyoffice/documentserver
```

Пока настройка пуста, всё работает по-прежнему — через печать. В организации
есть свои серверы ONLYOFFICE (`bench-preprod-oo.cml2.local:8350`,
`bench-prod-oo.cml2.local:8350`), но пускать через них документы по ГОЗ
можно только с согласия владельцев CML-Bench: сервер скачивает файл к себе
и держит его в кэше.
