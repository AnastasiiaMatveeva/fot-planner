# Слепок дизайн-системы продукта

Здесь лежит копия дизайн-системы «ФОТ · Планирование» — артефакта
`https://claude.ai/artifact/ALWjWL8Y4bHLtCXmWJ8dSE`. Копия, а не источник:
править нужно сам артефакт, отсюда изменения не уезжают обратно.

Копия нужна по двум причинам. Первая — сервис работает в сети организации, и
правила интерфейса должны читаться без выхода наружу. Вторая — по ней видно,
что именно изменилось в системе: сверка нового с этим слепком показывает
расхождение построчно, а не «что-то поменялось».

## Состав

| путь | что |
| --- | --- |
| `README.md` | бренд-бук: принципы, тон, цвет, типографика, действия, сетка, доступность |
| `tokens.json` | токены: цвет, типографика, отступы, радиусы, тени, размеры, штрихи |
| `design-system.json` | указатель системы; `lastChange` — кто и когда правил |
| `guidelines/` | девять сводов: действия, приёмы из Excel, паттерны экранов, реестр, числа и форматы, разбор стенда, логика и навигация, модель и связи, проверенные решения |
| `components/` | по файлу на компонент: что даёт потребитель и правила |

Превью компонентов и бандл не копируются: они исполняемые и нужны в самом
артефакте, а не здесь.

## Кто обновляет

Задача `sverit-dizayn-sistemu` в планировщике Claude (`Проверить дизайн-систему`)
раз в сутки читает артефакт, сверяет с этим слепком и, если система изменилась,
докладывает расхождения и что из них уже расходится с приложением. Слепок
обновляет она же — вместе с докладом, чтобы следующая сверка считала от нового
состояния.

Обновить вручную можно в любой момент: попросить прочитать артефакт и
переписать эти файлы.

## Что уже сведено с приложением

(`lastChange` 2026-09-17T22:21:36Z: своды 45, 50, 55).

- Токены цвета, размеров, радиусов и теней — в `:root` файла `app/static/app.css`.
- Гарнитуры Golos Text и PT Mono — `app/static/fonts.css`, файлы рядом.

  шифр моноширинным, «⋮» в той же строке, счётчики вкладок внутри записи сняты.

- Таблицы: шапка прописными `column-head`, зебры нет.
- По разбору стенда (`guidelines/40-razbor-interfeysa.md`): заголовок раздела
  `title`, заголовок панели `subtitle`, подложка страницы `canvas`,
  наследование гарнитуры, межстрочные в пикселях (текстовых стилей на экране

- По `guidelines/55`: условие договора, переопределённое в плане (`.ovon`),
  набрано акцентом полужирным вместо заливки строки.

## Что не сведено и почему

| что | почему |
| --- | --- |
| «Не больше семи колонок» в разделах результата | красная линия: таблицы результата не урезаются |
| Убрать графу «Действие» из таблицы замечаний | то же |
| Сгруппировать шесть граф «Отклонение» | то же |
| Копейки и типографский минус в таблицах результата | формат чисел в разделах результата — решение человека |
| «ё» в подписях граф результата («Лицевой счет») | подпись графы результата меняется только с ведома человека |
| `stepper`, `multiselect` чипами, `daterange`, кликабельный источник в `PropertySheet` | нужны редакторы, которых нет |
| «2 из 5» и перелистывание записей в шапке | меняет поведение, нужна позиция записи в списке |
| Три группы вкладок реестра (`guidelines/25`) | перестройка экрана, нужна сессия с человеком |
| Первичное действие на вкладку («Загрузить версию») | спорит с UI-006, решает человек |
| Один раздел «Документы» вместо двух мест | перестройка экрана |
| Уровни заголовков h1 → h2 → h3 в отчёте | разметка отчёта, нужна сессия с человеком |
| Адреса разделов и замечаний, «Назад», один скролл на страницу, реестр и план разными экранами (`guidelines/45`) | меняет поведение и навигацию, нужна сессия с человеком |
| Шифр договора ссылкой везде, «Используется в планах» в карточке (`45`, `50`) | новая связь и данные API |
| Замечание из трёх частей, кнопка «Перейти» с назначением (`45`, `50`) | текст и состав таблицы замечаний — раздел результата, решает человек |
| Поиск по плану по «/», сравнение вариантов, строка «чем отличается» (`45`) | новые компоненты |
| Статус «рассчитан на неполных данных», «Пересчитать» со счётчиком правок (`45`, `55`) | меняет поведение, нужны данные сервера |
| Метка ячейки, изменённой системой (`45`) | нужен признак в данных |
| Порядок разделов плана по смыслу (`45`) | состав раздела результата, красная линия |
| «Удалить документ» и «Удалить план» под «⋮» с чертой и подтверждением (`45`) | меняет поведение |
| Предел и источник рядом с каждым числом-результатом, клик по пределу к полю (`50`) | меняет состав таблиц результата, решает человек |
| Ставка счётчиком шага 0,25, оклад по месяцам (`50`) | нужен редактор и данные |
| Меню графы, закрепления правым кликом, вкладки карточки договора, версии документов (`55`) | новые компоненты и поведение |
