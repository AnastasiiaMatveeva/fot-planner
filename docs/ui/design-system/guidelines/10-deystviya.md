# Действия: где текст, где иконка, где ничего

Кнопка с текстом — самый дорогой способ предложить действие: она занимает ширину, повторяется в каждой строке и требует прочтения. В плотном интерфейсе большинство действий показываются иначе.

## Лестница видимости

Выбирайте самую нижнюю ступень, на которой действие остаётся находимым.

1. **Кнопка с текстом** — первичное действие страницы («Рассчитать план») и необратимое («Удалить расчёт»). Одна первичная на экран.
2. **Иконка с подсказкой** — общеизвестные действия: скачать, копировать, развернуть, добавить, удалить. Обязательны `aria-label` и подсказка при наведении.
3. **Иконка, проявляющаяся по наведению** — действия строки таблицы. Видна у строки под курсором, у строки с фокусом и у выбранной; на сенсорных экранах — всегда.
4. **Вертикальные точки «⋮»** — всё редкое: дублировать, перенести в другой вариант, история изменений, удалить. То же меню открывается правым кликом по строке.
5. **Сам объект и есть контрол** — переименование по клику на название, правка числа по клику на ячейку, сортировка по клику на заголовок колонки, копирование кода по клику на код, открытие по двойному клику. Кнопка не нужна вовсе.
6. **Ничего** — действие делает система: пересчёт после правки, автосохранение черновика, обновление итогов.

## Обязательные приглашения

Неявное действие работает, только если о нём видно до клика. Каждому — свой знак при наведении:

- Название, которое правится: подложка `surface-hover`, тонкий контур `border` и карандаш справа.
- Ячейка, которая правится: пунктирное подчёркивание `border-control`.
- Код, который копируется: пунктир и курсор `copy`.
- Заголовок колонки с сортировкой: стрелка, проявляющаяся при наведении на шапку.
- Строка с действиями: иконки справа.
- Место, куда добавляют: «+» последней строкой или область с «+» и подписью.

Действие без приглашения считается несуществующим. Это же правило отвечает на вопрос «а как я узнаю»: пользователь узнаёт, наведя курсор, и один раз.

## Правила

- Каждое действие доступно минимум двумя способами, один из которых — клавиатура. «⋮» дублируется правым кликом, двойной клик — клавишей Enter, правка ячейки — Enter на ней.
- Enter сохраняет, Esc отменяет, Tab сохраняет и переходит дальше. Везде одинаково.
- Необратимое действие не прячут за иконкой без слова и всегда подтверждают. Подтверждение называет объект: «Удалить расчёт № 3 от 09.09.2026?».
- Результат любого действия виден сразу: пересчитанная строка, обновлённый итог, короткое уведомление. Молчание читается как «не сработало».
- Отмена важнее подтверждения: там, где можно, вместо диалога показывайте уведомление с «Отменить» на 10 секунд.
- Отключённое действие не прячут: его отключают и объясняют причину подсказкой.
- Одно и то же действие называется одинаково во всех местах: в кнопке, в меню и в подтверждении.
