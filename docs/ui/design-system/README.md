Система для внутренних инструментов планирования фонда оплаты труда: плотные таблицы, суммы в рублях, длинные согласования. Экономист смотрит в этот интерфейс по шесть часов в день и ищет в нём числа, а не впечатления. Всё, что не помогает быстрее найти и сверить число, из макета убирается.

## Принципы

1. **Бланк, а не приложение.** Белая плоскость, тонкие линии, малые радиусы, никаких заливок ради украшения. Ориентиры — SAP Fiori, Workday, бухгалтерский бланк; не дашборды потребительских приложений.
2. **Иерархию держат размер, вес и расстояние.** Цвет и рамки — последнее средство. Если блок «сливается», сначала измените размер шрифта или отступ, и только потом добавляйте линию.
3. **Цвет означает.** В интерфейсе ровно один акцентный цвет — `accent` — и три сигнальных: `success`, `warning`, `danger`. Никакой декоративной раскраски, градиентов и цветных карточек.
4. **Число — главный контент.** Числа выравниваются по правому краю, набираются табличными цифрами, никогда не переносятся и не сокращаются без подписи единиц.
5. **Действие живёт на объекте.** Переименование — клик по названию, правка — клик по ячейке, редкое — под «⋮». Кнопка с текстом остаётся только у первичного и необратимого действия.
6. **Плотность — это уважение.** Пустое место тратится только там, где оно разделяет смысл. Строка таблицы — `row-md` (34px), базовый текст — `body` (13px).

## Тон и содержание

- Обращение на «вы», без восклицательных знаков и эмодзи. Эмодзи не используются нигде, включая статусы.
- Заголовки, кнопки и пункты меню — предложение с заглавной буквы: «Рассчитать план», не «Рассчитать План» и не «РАССЧИТАТЬ». Прописными набирается только стиль `column-head`.
- «ё» пишется: «Расчёт», «Учёт», «Приём».
- Один термин — одно значение на весь продукт. Договор, Расчёт, Замечание, Факт, Предел, Отклонение, Освоение, Ставка, Трудоёмкость, Исполнитель, Дефицит. Не заменяйте термин синонимом ради разнообразия.
- Кнопка называется действием, а не объектом: «Рассчитать план», «Скачать выгрузку», «Удалить расчёт». Одно действие называется одинаково в кнопке, в меню и в подтверждении.
- Ошибка объясняет, что сделать: «Не заполнен предел ФОТ по договору C_BASE-26» вместо «Ошибка валидации».
- Пустое состояние — одна строка `body` в `ink-secondary` и, если действие очевидно, «+» на месте будущего объекта. Без иллюстраций.

## Цвет

- Фон страницы — `canvas`, чуть тёплый, как бумага; содержимое — панели на `surface`. Разница в один шаг и есть разделение экрана; не добавляйте к панели ещё и тень.
- `surface-selected` намеренно холоднее остальных поверхностей: выбор — состояние системы, а не свойство бумаги.
- Основной текст — `ink`. Подписи полей и заголовки колонок — `ink-secondary`. Единицы, плейсхолдеры и служебные метки — `ink-muted`. Больше трёх уровней серого на экране не бывает.
- `accent` приглушён намеренно: он должен уступать числам. Тратится экономно — одна первичная кнопка на экран, индикатор активной вкладки, ссылки, полоса слева у выбранной строки. Если акцентных пятен больше трёх — акцента нет.
- **Статус в строке — слово цветом статуса с вертикальной чертой (`Status`), без заливки.** Залитая плашка (`Badge`) остаётся ровно одна на экран — статус плана в шапке страницы. Сорок пастельных прямоугольников в таблице перетягивают внимание с чисел и сливаются при печати.
- Рядом с `success`, `warning` и `danger` всегда стоит слово. Экономист печатает и пересылает эти экраны в чёрно-белом виде.
- Подложки `success-subtle`, `warning-subtle`, `danger-subtle` применяются только к подсветке строки-нарушения и к единственной плашке в шапке; текст на них берётся из парного токена.
- Суммы по умолчанию — `figure-neutral`. `figure-negative` — для отрицательных значений и отклонений вниз, `figure-positive` — только там, где рост действительно хорош.
- Отключённые элементы — `ink-disabled` и `opacity-disabled`; данные этим цветом не передаются никогда.

## Типографика

- Гарнитуры: `sans` — **Golos Text** (Paratype, рисовалась для русскоязычных корпоративных и государственных интерфейсов: узкая, сухая, с ровными цифрами), `mono` — **PT Mono** для кодов договоров и идентификаторов. Обе бесплатны. В продакшене шрифты размещаются на своём домене; система ссылается на них по именам семейств.
- Базовый текст и ячейки — `body`. Ключ строки — `body-strong`. Статус — `status`. Заголовок панели — `subtitle`, заголовок раздела — `title`, название плана — `display` (один на экран).
- Все числа набираются стилями группы «Числа» и всегда с `font-variant-numeric: tabular-nums` — иначе разряды в соседних строках не совпадут по вертикали.
- Заголовки колонок — `column-head` прописными с трекингом; это единственное место, где допустим caps.
- Не используйте более четырёх текстовых стилей в одной панели.

## Действия

Полные правила — в разделе «Действия: где текст, где иконка, где ничего». Коротко:

- Текст в кнопке — только у первичного действия страницы и у необратимого.
- Общеизвестные действия (скачать, копировать, добавить, развернуть, удалить) — иконкой с `aria-label` и подсказкой.
- Действия строки — иконки, проявляющиеся по наведению и по фокусу, плюс «⋮» для редкого; то же меню открывает правый клик.
- Название правится кликом по названию, число — кликом по ячейке, сортировка — кликом по заголовку, открытие — двойным кликом.
- Добавление — «+» последней строкой таблицы или область с «+» для файлов, а не кнопка в шапке.
- У каждого неявного действия есть видимое приглашение при наведении: подложка с карандашом, пунктирное подчёркивание, стрелка сортировки, иконки справа.

## Сетка, плотность и разделение

- Шаг сетки — 4px, от `space-1` до `space-12`. Внутри таблиц и панелей крупнее `space-4` не отступаем.
- Поля ячейки — `space-3` по горизонтали; высота строки — `row-md`, шапки — `row-head`. Строка с двумя уровнями текста — `row-lg`.
- Поля панели — `space-4`, расстояние между панелями — `space-5`, поля области контента — `space-6`.
- Разделяйте в таком порядке: сначала расстоянием, затем сменой фона (`surface` → `surface-sunken`), затем линией `border-subtle`, и только в последнюю очередь — рамкой `border`. Двумя способами сразу одно и то же не разделяют.
- Чересполосицу (зебру) не применяем: строки разделяет линия `border-subtle`, наведение — `surface-hover`, выбор — `surface-selected` плюс полоса `accent` шириной `stroke-emphasis` слева.
- Таблица тянется на всю доступную ширину; текстовые блоки ограничены `content-max`.

## Границы, радиусы, тени

- Толщина всех линий — `stroke-hairline`. Двойных рамок не бывает.
- Радиусы: контролы — `radius-sm`, панели и карточки — `radius-md`, модальные окна — `radius-lg`. Значения крупнее дают «мягкий» вид, неуместный в финансовом инструменте.
- Тень означает слой над страницей и только его: `shadow-sm` — закреплённая шапка при прокрутке, `shadow-raised` — меню и поповер, `shadow-overlay` — модальное окно. Панель на странице тени не имеет.

## Состояния

- Наведение — `surface-hover` для строк и пунктов, `accent-hover` для акцентных элементов. Курсор меняется только там, где есть действие.
- Фокус с клавиатуры виден всегда: кольцо `stroke-focus` цветом `focus-ring` со смещением 1px. На заливках `accent` и `danger` вместо него используется внутреннее кольцо `focus-ring-on-fill`.
- Скрытые по наведению действия обязаны проявляться и по фокусу с клавиатуры (`:focus-within`), иначе они недоступны без мыши.
- Загрузка длинного расчёта: таблица остаётся на месте с `opacity-loading` и полосой прогресса; скелетоны вместо данных не рисуем, чтобы не создавать иллюзию цифр.
- Отключённая кнопка объясняет причину подсказкой; `disabled` без объяснения запрещён.

## Иконки

- Отдельного набора иконок бренд не предоставил. В бандле лежит временный минимальный набор `Glyphs` (плюс, карандаш, корзина, скачать, копировать, развернуть, вертикальные точки, три знака статуса) — контурный, 16px, толщина `stroke-icon`, цвет `currentColor`. **Это осознанная замена: её нужно заменить фирменным набором.** До этого можно взять один готовый комплект целиком (Lucide, Phosphor или Remix Icon) и не смешивать их.
- Размеры: `icon-sm` в статусах и подписях, `icon-md` в кнопках, полях, меню и действиях строки, `icon-lg` в пустых состояниях.
- Иконка без текста допустима только для общеизвестных действий и обязана иметь `aria-label` и подсказку.
- Иконка никогда не передаёт статус в одиночку — только вместе со словом.

## Доступность

- Текст держит 4.5:1 к своему фону, крупный (от 24px или полужирный от 19px) — 3:1, границы контролов, кольцо фокуса и значащие иконки — 3:1. Проверено для обеих тем.
- Весь интерфейс проходится с клавиатуры; порядок табуляции идёт слева направо и сверху вниз по визуальному порядку.
- Таблицы размечаются `th` с `scope`, числовые колонки — `text-align: right`.
- Статус дублируется словом; цвет никогда не единственный носитель смысла.
- Действие, доступное только по наведению, всегда имеет клавиатурный и контекстный дубль.

## Логотип

Фирменного знака в исходных материалах нет. До его появления название продукта набирается стилем `title` обычным текстом: «CML‑Bench® 2.0», подпись модуля — `caption` в `ink-secondary`. Знак не рисуется и не восстанавливается по памяти.
