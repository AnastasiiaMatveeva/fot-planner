Боковая навигация: название продукта, разделы приложения, список планов.

**Что даёт потребитель:** `product` и `module` для шапки, `groups` (заголовок группы, необязательное действие, список пунктов), `value` и `onChange`.

## Правила

- В навигации **только переходы**. Действия над данными («Рассчитать», «Удалить») в неё не попадают; исключение — одно действие создания в заголовке группы («+» для нового плана).
- Активный пункт: фон `surface-selected`, текст `ink` полужирным, полоса `accent` слева. Цветом одним активность не передаётся.
- Длинные названия планов обрезаются многоточием в одну строку; полное название уходит в `title`. Два-три перенесённых названия подряд превращают колонку в текстовый блок и ломают сканирование.
- `meta` справа от пункта — короткий статус или год, `micro` в `ink-muted`: «2026», «черновик». Не больше одного слова.
- Заголовок группы — `column-head` прописными в `ink-muted`, без разделительной линии: группы разделяет отступ `space-4`.
- Ширина фиксирована (`sidebar-w`, 248px). Сворачивание в иконки не предусмотрено: пункты здесь называются словами, а не пиктограммами.
- Фон навигации — `canvas`, а контента — `surface`: контент выступает вперёд, навигация уходит назад.
