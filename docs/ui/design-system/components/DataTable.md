Плотная таблица данных: закреплённая шапка, числовые колонки, подсветка нарушений, итоговая строка.

**Что даёт потребитель:** `columns` (`key`, `title`, `numeric`, `mono`, `width`, `sortable`, `render`) и `rows` (`id`, значения по ключам колонок, `sub` для второй строки в первой колонке, `state` для подсветки). Итоги — `total`, выбор — `selectedId` и `onRowClick`. Взаимодействия: `sort`/`onSortChange` (сортировка кликом по заголовку), `onRowOpen` (двойной клик), `rowMenu` (правый клик), `rowActions` (иконки по наведению), `onAdd`/`addLabel` («+» последней строкой).

## Правила

- Текст выравнивается влево, числа — вправо (`numeric`), коды — моноширинным (`mono`). Заголовок колонки выравнивается так же, как её содержимое.
- **Зебры нет.** Строки разделяет `border-subtle`, наведение — `surface-hover`, выбранная строка — `surface-selected` и полоса `accent` слева.
- Первая колонка — ключ строки: `body-strong` плюс `sub` второй строкой («Договоры · За год»). Это вертикальный якорь, по которому глаз возвращается из числовых колонок.
- Ширины числовых колонок фиксируются, чтобы разряды совпадали между таблицами одного раздела.
- Статус в строке — `Status` (слово с вертикальной чертой), не плашка. `state: "flagged"` (охра) и `state: "breached"` (кирпич) подсвечивают строку целиком — только для нарушений и только вместе со статусом в строке. Подсветка без слова означает смысл одним цветом и запрещена.
- Действия строки живут в правой колонке без заголовка и проявляются по наведению, по фокусу и у выбранной строки. Текстовых кнопок в строках не бывает.
- Сортировка включается `sortable` на колонке; числовые колонки сортируются по величине, а не по строке. Таблица замечаний по умолчанию сортируется по модулю отклонения.
- `onAdd` добавляет «+ Добавить …» последней строкой; она не входит в `total` и не считается строкой данных.
- Больше семи колонок — повод спрятать часть в «Настроить колонки», а не уменьшать шрифт.
- `total` включает итоговую строку на `surface-sunken`; она закрепляется у нижнего края длинной таблицы.
- На время пересчёта — `loading`: таблица остаётся на месте с `opacity-loading`. Скелетоны вместо цифр не рисуем, чтобы не показывать несуществующие данные.
- Сортировка числовых колонок — по величине, а не по строке; по умолчанию таблица замечаний сортируется по модулю отклонения.
