Статус строки: слово цветом статуса с вертикальной чертой слева, без плашки.

**Что даёт потребитель:** текст в `children` и `tone` (`neutral`, `info`, `success`, `warning`, `danger`). `mark` выбирает знак слева: `rule` (вертикальная черта, по умолчанию), `icon` (контурная иконка) или `none`. `quiet` оставляет слово цветом `ink`, а цвет — только у знака.

## Почему не плашка

Залитая пастельная плашка на каждой строке даёт сорок цветных прямоугольников на экран: глаз цепляется за них вместо чисел, а при печати в чёрно-белом всё сливается. Вертикальная черта шириной `stroke-emphasis` занимает 2px, читается как пометка на полях бланка и не спорит с колонкой сумм. Плашка (`Badge`) остаётся ровно одна — статус плана в шапке страницы.

## Правила

- **Слово обязательно.** Черта и иконка — дополнение к нему, а не замена. Один цвет смысла не передаёт.
- Формулировка короткая и утвердительная: «Внимание», «Превышен предел», «В пределах», «Не рассчитан». Без точки.
- Тон по смыслу: `success` — проверка пройдена, `warning` — требует внимания, работа продолжается, `danger` — блокирует, `neutral` — состояние без оценки, `info` — состояние процесса.
- `mark="icon"` берут там, где статусов мало и нужен более сильный знак (карточка, шапка панели). В длинной таблице иконка в каждой строке шумит так же, как плашка, — там `rule`.
- `quiet` применяют, когда в строке уже есть цветное число: два цветных элемента рядом соперничают.
- Подсветка строки целиком (`warning-subtle`, `danger-subtle`) добавляется только к нарушениям и только вместе со статусом в строке.
