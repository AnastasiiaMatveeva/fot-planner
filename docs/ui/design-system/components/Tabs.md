Вкладки разделов плана: номер, название, точка-индикатор состояния.

**Что даёт потребитель:** `items` (`id`, `label`, при необходимости `index` и `flag`), текущее значение `value` и `onChange`.

## Правила

- Номер раздела — часть подписи. В плане ФОТ пятнадцать разделов, и на совещании их называют номером: «посмотри четвёртый, Касса». Номер набирается `micro` в `ink-muted` перед названием.
- Активная вкладка: текст `ink`, полужирный, подчёркивание `stroke-emphasis` цветом `accent`. Неактивные — `ink-secondary`. Никаких «таблеток», рамок и заливок: на 15 вкладок это превращается в сплошное пятно.
- `flag: "warning"` — в разделе есть замечания, `flag: "danger"` — есть блокирующие ошибки. Точка обязательно сопровождается словесной расшифровкой в `flagTitle`, иначе смысл передаётся одним цветом.
- Точки ставятся только там, где они есть. Точка у каждой вкладки не информирует ни о чём.
- Перенос на вторую строку разрешён и не отделяется дополнительной линией. Скрывающее меню «ещё» не применяем: экономисту нужно видеть все разделы сразу.
- Вкладки переключают разделы одной сущности и не заменяют навигацию по страницам — та живёт в `SideNav`.

## Группы разделов

Когда вкладки относятся к разным по природе сущностям (данные, справочники, источники), они получают `group` и `layout: "rows"`: **у каждой группы свой ряд с подписью слева**, ряды разделены волосяной линией, подписи выровнены по колонке 116px.

Разделители внутри одного ряда для этого не годятся: при переносе на вторую строку группы перемешиваются и ряд читается как каша. Ряд без групп (`layout` по умолчанию) остаётся для разделов одной сущности — например, пятнадцати разделов плана.

`count` показывает число записей раздела; `counts: false` прячет счётчики целиком — внутри записи они не нужны, потому что описывают списки.
