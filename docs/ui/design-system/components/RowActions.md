Действия строки: две иконки, проявляющиеся по наведению, и вертикальные точки для остального.

**Что даёт потребитель:** `quick` — до двух частых действий (`id`, `label`, `icon`, `onSelect`), `more` — остальные пунктами меню (те же поля плюс `danger`, `shortcut`, `separator`). Тот же список `more` передаётся в `DataTable` через `rowMenu`, чтобы правый клик открывал его же.

## Почему не кнопки с текстом

Текстовая кнопка в каждой строке съедает 100–150px ширины на сорока строках и повторяет одно и то же слово сорок раз. Иконка появляется только у строки под курсором, а всё редкое прячется под «⋮». Ширина уходит числам.

## Правила

- `quick` — не больше двух. Только общеизвестные действия: изменить, копировать, скачать, удалить. Всё остальное — в `more`.
- Каждая иконка обязана иметь `label`: он уходит и в `aria-label`, и в подсказку при наведении. Иконка без подписи нечитаема для того, кто видит её впервые.
- Действия проявляются по наведению, **по фокусу с клавиатуры и у выбранной строки** — иначе с клавиатуры до них не добраться. На сенсорных экранах они видны всегда.
- Удаление живёт в `more` с `danger: true` и всегда спрашивает подтверждение. Необратимое действие не прячут за иконкой без слова.
- Одно и то же меню открывается тремя способами: «⋮», правый клик по строке, клавиша контекстного меню. Пользователь не должен угадывать единственный верный.
- В `shortcut` пишут реальную горячую клавишу, а не украшение.
- Первичное действие страницы («Рассчитать план») в строке не дублируется.
