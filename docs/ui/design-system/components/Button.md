Кнопка действия: четыре варианта и три размера, по умолчанию вторичная.

**Что даёт потребитель:** текст действия в `children`, `variant`, `size`, при необходимости `icon` (SVG 16px с `currentColor`) и `onClick`. Для кнопки без текста — `iconOnly` вместе с `label`, который уходит в `aria-label`.

## Сначала решите, нужна ли кнопка

Текстовая кнопка — самый дорогой способ предложить действие. Текст оставляют ровно в двух случаях: первичное действие страницы и необратимое. Всё остальное показывается иконкой с подсказкой, действием строки по наведению, пунктом под «⋮» или вовсе кликом по самому объекту — см. раздел «Действия: где текст, где иконка, где ничего».

## Когда какой вариант

- `primary` — главное действие страницы: «Рассчитать план», «Сохранить». **Одна на экран.** Если первичных кнопок две, значит иерархия действий не определена.
- `secondary` — все обычные действия: «Отменить», «Добавить договор», «Настроить колонки».
- `ghost` — действия внутри панели и строки таблицы, где рамка создала бы шум.
- `danger` — необратимые действия: «Удалить расчёт». Только в подтверждающем диалоге, не в общем ряду кнопок.

## Размеры

- `lg` (`control-lg`) — первичное действие в шапке страницы и в модальном окне.
- `md` (`control-md`) — размер по умолчанию.
- `sm` (`control-sm`) — панель инструментов над таблицей, действия в строке.

## Правила

- Называйте действием, а не объектом: «Скачать выгрузку», не «Выгрузка».
- Не более одной `primary` и не более четырёх кнопок в ряду; остальное уходит в меню.
- Отключённая кнопка всегда объясняет причину подсказкой; `disabled` без объяснения запрещён.
- Иконка без текста допустима только для общеизвестных действий (удалить, скачать, развернуть).
- Фокус на `primary` и `danger` рисуется внутренним кольцом `focus-ring-on-fill` — не переопределяйте `outline` руками.
