Сервис планирования фонда оплаты труда

CML, демонстрационные материалы

Сервис распределяет средства договоров по сотрудникам и месяцам так, чтобы каждому была выплачена установленная месячная заработная плата при соблюдении всех ограничений договоров, предельных размеров выплат и кассы. Обработку документов выполняют ИИ-агенты, расчёт денежных величин — детерминированная оптимизационная модель.

Схема работы

от подписанных документов до плана выплат

ИИ-агенты

семь агентов, ни один не выполняет расчёт денежных величин
ИИ-агент 1, ввод данныхИзвлечение данных из документов

Обрабатывает расчётно-калькуляционные материалы по ГОЗ и структуры цены, извлекает целевые показатели в паспорт договора, принимает вложения служебной переписки.

Контроль
  • каждое значение проверяется расчётным соотношением самой формы
  • несошедшееся значение останавливается и передаётся экономисту одним вопросом с вариантами
ИИ-агент 2, настройка расчётаНастройка параметров оптимизационной модели

Преобразует требование специалиста, сформулированное на естественном языке, в веса целевой функции: «минимизировать приказы» повышает штраф использования приказа, «равномерное освоение ГОЗ» — штраф неравномерности.

Граница
  • изменяет только веса предпочтений, жёсткие ограничения недоступны
ИИ-агент 3, анализ отказаАнализ причин невыполнимости задачи

При отсутствии допустимого решения формирует содержательное заключение вместо технического отказа: выделяет минимальный набор взаимно противоречивых ограничений, называет величину разрыва в рублях и предлагает варианты устранения с ценой каждого.

ИИ-агент 4, вариантный анализСценарное моделирование

Формирует изменённые исходные данные, выполняет расчёт тем же решателем и представляет отличия от базового плана: сокращение фонда, увольнение сотрудника, перенос поступления.

ИИ-агент 5, сопровождениеСверка плановых и фактических начислений

Ежемесячно сопоставляет выгрузку начислений бухгалтерии с плановыми строками: различное написание фамилий, несовпадающие коды, несколько позиций штатного расписания у одного сотрудника, выплаты вне плана.

Контроль
  • итоговая сумма по сотруднику сходится с точностью до рубля либо строка помечается
ИИ-агент 6, выходные материалыФормирование пояснительных материалов

Формирует текст пояснительной записки и служебных писем по результатам расчёта: почему применена стимулирующая приказом, почему остаток не освоен, какое ограничение оказалось связывающим. Оперирует только числами результата.

ИИ-агент 7, нормативная базаМониторинг нормативной базы

Контролирует приказы и положение об оплате труда, выявляет неактуальные значения в справочниках: предельные размеры по приказам 2556 и 4, оклады должностей, среднемесячную зарплату основных работников из писем военного представительства.

Оптимизатор

смешанное целочисленное программирование, Pyomo и HiGHS

Что гарантирует

  • решение либо удовлетворяет всем жёстким ограничениям, либо задача объявляется невыполнимой
  • ограничения выполняются по построению модели, а не проверяются постфактум
  • при одинаковых исходных данных результат воспроизводим
  • дефицит, если он разрешён, показывается адресно: сотрудник, месяц, договор, сумма

Что минимизирует

  • смены источника оклада в течение года
  • административную сложность: лишние связки сотрудник—договор
  • дробление выплат между договорами
  • неравномерность освоения фонда по месяцам
  • применение стимулирующей приказом

выполняются одновременно

Если решения нет

  • при запрете дефицита задача объявляется невыполнимой, ИИ-агент 3 разбирает причины
  • при разрешённом дефиците возвращается частичный план с адресными недоплатами
  • неосвоенный остаток договора не блокирует расчёт и выносится в предупреждения

Пересчёт по факту

  • закрытые месяцы фиксируются фактическими начислениями и становятся ограничением
  • пересчитывается только остаток года
  • договорные величины неизменны: трудоёмкость, ФОТ, предельные размеры
Реализация: Python, Pyomo, HiGHS, openpyxl. Вход и выход — книги Excel. Контур извлечения документов и агентные функции 2—7 находятся в разработке; оптимизатор и отчётность реализованы.
