# docs/ui: модули разбора и схема сервиса

Прототип интерфейса, который жил здесь в августе — начале сентября 2026, удалён
11.09.2026: его заменило приложение `app/`. Остались файлы, которыми пользуется
приложение, и схема сервиса. Прототип и его прежние версии есть в истории git.

| Файл | Кто пользуется |
| --- | --- |
| `extract.py` | якорный разбор документов по маркерам листов: `app/intake.py`, `scripts/demo_offline.py`, `harness/run.py`, `tests/test_extract_fot_detail.py` |
| `result2json.py` | результат решателя из xlsx в json для отчёта: `app/main.py` |
| `demo_input.xlsx` | шаблон входа решателя, из него берётся справочник должностей: `app/reference.py` |
| `about.html` | схема и описание сервиса: агенты, оптимизатор, вход, выход, ограничения |

Модули лежат здесь по истории, а не по смыслу: приложение подключает папку
через `sys.path`.
