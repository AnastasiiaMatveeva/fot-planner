# Задание на разработку интерфейса по макету

Для агента или разработчика, который будет делать интерфейс. Макет — не картинка
для вдохновения, а состав экранов, термины и поведение таблиц. Расходиться с ним
можно, но осознанно и с записью причины.

## Что читать и в каком порядке

1. `docs/ИНТЕРФЕЙС.md` — карточки UI-001…UI-009. Это правила, макет им подчинён.
   При расхождении макета и карточки права карточка, а расхождение — ошибка макета.
2. `README.md` рядом — что это за макет, статус, открытые вопросы.
3. `project/*.dc.html` — исходники экранов. **Источник истины по составу граф,
   названиям и данным.** Разметка вперемешку с данными и логикой: смотреть надо
   и то и другое.
4. `html/*.html` — те же экраны, открываются браузером.

Экраны открываются только с сервера, не двойным щелчком: они подключают
`html/support.js`, а из `file://` он не грузится.

```bash
cd docs/ui/mockup/html && python -m http.server 8777
```

Дальше `http://127.0.0.1:8777/Main.html`. Между экранами есть ссылки.

## Из чего состоит макет

| Файл | Экран | На какой вопрос отвечает |
| --- | --- | --- |
| `Main` | Реестр | что есть у организации: договоры, трудоёмкость по месяцам, категории договоров |
| `Contract` | Карточка договора | что у договора есть и откуда это взято |
| `NewContract` | Создание договора | выбор файлов одного договора, больше ничего |
| `Plan` | План | состав, условия расчёта, четырнадцать разделов «Плана ФОТ», контроль, лента |
| `NoSolution` | Решения нет | какие жёсткие условия несовместимы и что можно изменить |
| `Employees` | Кадры | штатное расписание, зарплата по месяцам, 120 надбавка, справочники |
| `Help` | Инструкция | четыре шага и почему ответов два |

`project/canvas.json` — раскладка досок и заметки; для разработки не нужен.

## Что макет требует от каждой таблицы

Это не оформление, это поведение. Экономист работает в Excel и 1С и ждёт того же.

- **Меню графы** у каждой графы плоского списка: сортировка по возрастанию и по
  убыванию, группировка с промежуточными итогами, отбор по значениям флажками,
  «Снять отбор с графы». Значок — воронка, серая без отбора, синяя с отбором.
- **Значения в меню отбора** по возрастанию: числа по величине, даты по
  хронологии, остальное по алфавиту; «не найдено» и «не заполнено» в конец.
  Показываются все, список прокручивается.
- **Стрелка сортировки** только у той графы, по которой сортируют.
- **Выбор граф** кнопкой «Графы»: набор по умолчанию и полный список.
- **Выделение клеток** щелчком, счёт выделенного в нижней полосе: количество,
  сумма, среднее. Как строка состояния Excel — пока ничего не выделено, молчит.
- **Нижняя полоса**: строк на странице, счёт строк, страницы. Счёт строк живёт
  здесь, а не в заголовке.
- **Пустое состояние**: «Ничего не найдено: снимите отбор в графах».
- **Закрепление граф** слева там, где таблица шире экрана (трудоёмкость с
  двенадцатью месяцами).
- Сортировки и меню **нет** у деревьев (каталог документов: сортировка отрывает
  редакции от документа) и у карточек объекта (реквизиты договора: порядок в них
  содержательный).

## Термины: как называть и почему

Имена взяты из свода правил решателя, 1С и форм РКМ. Не переименовывать без
причины: за каждым стоит разбор.

| Термин | Что это | Откуда имя |
| --- | --- | --- |
| Категория договора | ГОЗ · Коммерческий · Грант · Кооперация МПТ | классификатор; отдельного признака «ГОЗ» нет, он значение категории |
| Приоритет 2030 | режим выплат: на договоре либо штатные виды, либо 152 | правило 12 `ПРАВИЛА_РЕШАТЕЛЯ.md`, поле `priority_payment_mode` |
| Учитывать в расчёте | входит ли договор в этот план | графа плана, не свойство договора |
| Группировать по этой графе | группировка с итогами | термин 1С; «промежуточные итоги» в Excel — другое действие |
| Распределение по месяцам | есть ли помесячный план трудоёмкости | `ContractLaborPlan`: чел.-мес. хранятся по месяцам, не диапазоном дат |
| Правок условий | сколько условий договора перебито в этом плане | открывает окно условий |

Убраны намеренно: «Состояние пакета» и «Не хватает документов» — это оценка
разбора, а не факт договора; на вопрос «разобрался ли документ» отвечает графа
«Состояние» в каталоге документов.

## Что в макете показано честно как нереализованное

Не выдавать за работающее:

- **Раздел «Контроль»** на экране плана: пять проверок QA-001 со статусом «не
  реализована», плюс `решатель · стадии` и `решатель · остатки`.
- **Порядок стадий оптимизации** настраивается стрелками на экране, но расчёт
  берёт порядок из кода. В «Справке» это сказано прямо.
- **Перетаскивание файлов** в окне создания: показана только рамка, обработки нет.
- **Клавиатура в меню графы**: `aria-haspopup` и `aria-expanded` проставлены,
  ходьба стрелками и Esc не сделаны. В готовом интерфейсе нужны.
- **Модальные окна** не перехватывают фокус и не закрываются по Esc.

## Чего в макете нет и додумывать нельзя

Четыре вопроса продукта. Ответы меняют расчёт, а не разметку; они в `README.md`
рядом, с указанием, где обсуждаются. Коротко:

1. Свой срок выплат у каждого вида надбавки — сейчас две даты на договор.
2. Правила по категориям договоров — сейчас общие настройки с именами по ГОЗ.
3. «Приоритет 2030» — свойство договора или категории.
4. Настройка порядка стадий оптимизации.

Пока решения нет, реализовывать надо как в расчёте сегодня, а не как на макете.

## Чем макет сделан и что из этого переносить

Разметка макета — простые div-таблицы на CSS-сетке и flex, без библиотек, с
инлайновыми стилями там, где это разовая раскладка. Переносить это как код не
нужно: берите состав, названия, поведение и числа. Что стоит перенести:

- шкала кеглей 11 / 12,5 / 13 / 16 / 20 пикселей, по одному на роль;
- три ступени серого для текста: `#17191C` основной, `#3B424A` второй уровень,
  `#5C636B` приглушённый; `#7A828A` только для значков;
- один акцент `#1F4FA8`; жёлтый `#8A5A00` — изменено или под вопросом, красный
  `#A4382C` — нарушение;
- числа в графах моноширинными цифрами (`tabular-nums`);
- переход 120 мс на цвет, фон и рамку, со снятием при `prefers-reduced-motion`;
- `:focus-visible`, а не `:focus`.

`html/support.js` — самодельная среда, которая разворачивает шаблоны макета в
браузере. Нужна только чтобы смотреть; в разработку её не тащить.
