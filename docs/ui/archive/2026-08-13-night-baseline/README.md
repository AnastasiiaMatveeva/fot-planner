# Демонстрационные материалы

Две самодостаточные HTML-страницы. Внешних зависимостей нет: ни интернета, ни сервера,
ни сборки. Работают офлайн, их можно отправить письмом или положить на флешку.

| Файл | Что это |
|------|---------|
| `prototype.html` | Интерактивный прототип интерфейса: загрузка документов, агент-парсер, агент-калибровщик, оптимизатор, план выплат |
| `about.html` | Статичная схема и описание сервиса: агенты, оптимизатор, вход, выход, условия и ограничения |

## Как открыть

Двойной клик по файлу. Откроется в браузере по умолчанию.

Из консоли:

```bash
start docs/ui/prototype.html
```

## Показ по сети

Нужно, только если смотреть надо с другого устройства — с телефона, планшета или
чужого ноутбука в той же сети.

```bash
python -m http.server 8000 --directory docs/ui
```

Дальше `http://localhost:8000/prototype.html` на этой машине,
либо `http://<ваш-ip>:8000/prototype.html` с другого устройства в той же сети.

Остановить — `Ctrl+C` в том же окне консоли. Пока команда не запущена, адрес
`localhost:8000` не отвечает — это нормально, а не ошибка.

## Данные

Прототип показывает синтетический набор: 100 сотрудников, 20 договоров четырёх типов
(ГОЗ, грант, внебюджет, госзадание), этапы и трудоёмкость.

Справочные величины взяты из репозитория и соответствуют коду:

- оклады должностей — `src/fot_planner/defaults/position_reference.py`
- П2556 и П4 — `src/fot_planner/defaults/position_limits.py`
- параметры целевой функции — `src/fot_planner/defaults/settings.py`

План выплат в прототипе не является выходом решателя: на масштабе 100×20 солвер
не сошёлся за 10 минут, поэтому раскладка подготовлена отдельно. Ограничения и
номенклатура выплат при этом настоящие.

## Правка

Файлы самодостаточные: разметка, стили и скрипт лежат внутри одного `.html`.
Правится любым редактором, пересборка не нужна — достаточно обновить страницу
в браузере.
