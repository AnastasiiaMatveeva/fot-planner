# Демо-набор

Канонический демо-набор хранится в `data/demo/` и воспроизводится скриптами.
Числа из старой локальной памяти сюда не перенесены: итог меняется вместе с
правилами, поэтому его подтверждает новый прогон, а не записанная вручную
сумма.

## Состав

- `data/demo/Договоры 2026.xlsx`;
- `data/demo/Штатное расписание 2026.xlsx`;
- `data/demo/РКМ ГОЗ Радар-26.xlsx`;
- `data/demo/Структура цены Грант-26.xlsx`;
- образцы форм в `data/demo/forms/`.

Набор обезличен и хранится в git. `app/data/` в него не входит.

## Воспроизведение

```bash
.venv/Scripts/python.exe scripts/create_demo_docs.py
.venv/Scripts/python.exe scripts/demo_offline.py --out outputs/demo
.venv/Scripts/python.exe scripts/check.py --full
```

Через работающее приложение используется `scripts/demo_run.py`; запуск может
менять данные приложения, поэтому перед ним надо проверить выбранную базу и
получить разрешение согласно `AGENTS.md`.

Результат конкретного показа не хранится как источник требований. Актуальные
цифры подтверждаются свежим прогоном и его артефактами.

## Комплект для загрузки руками

`data/demo_pack/` — те же правила, разложенные по папкам так, как документы
приносят в отдел: штатное расписание, папка на каждый договор с его карточкой
и документами трудоёмкости (РКМ ГОЗ, структура цены расширенная и простая в
часах, план работ по месяцам), зарплата по месяцам с ростом у части людей и
факт января формой 6.3. Состав и порядок — `DEV-DEMO-PACK-001` в
`docs/ТЕСТИРОВАНИЕ.md` и «Порядок загрузки.txt» в самой папке.

```bash
.venv/Scripts/python.exe scripts/create_demo_pack.py --fact январь.json
FOT_BASE_URL=http://127.0.0.1:8771 .venv/Scripts/python.exe scripts/demo_pack.py clean
FOT_BASE_URL=http://127.0.0.1:8771 .venv/Scripts/python.exe scripts/demo_pack.py load
```
