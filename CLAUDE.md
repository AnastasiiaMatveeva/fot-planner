# Claude Code в fot-planner

Общие правила работы лежат в `AGENTS.md`. В начале сессии прочитай его и
`docs/README.md`, затем канонический документ по своей задаче.

## Файлы Claude Code

- `.claude/settings.json` — общие разрешения и хуки, хранится в git;
- `.claude/launch.json` — переносимые конфигурации запуска, хранится в git;
- `.claude/settings.local.json` — настройки конкретного компьютера, игнорируется
  git и не содержит требований проекта.

Локальная память Claude в профиле пользователя может хранить личные привычки
работы, но не правила продукта, источники чисел или критерии приёмки. Если в ней
обнаружено полезное проектное решение, перенеси его в соответствующий файл
`docs/` и отметь источник и статус. При конфликте не угадывай — запиши вопрос.

Хуки помогают не забыть проверку, но их успешное завершение не заменяет
приёмку из `AGENTS.md`.
